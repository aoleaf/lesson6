# 自己紹介ページ

HTML と CSS で作成した、シンプルな自己紹介ページです。

## 概要

カードデザインの自己紹介ページです。趣味の一覧やスキルのプログレスバーを掲載しています。ページ表示時のフェードインアニメーションや、スキルバーの伸長アニメーションも実装しています。

## スクリーンショット

![自己紹介ページ](photo.PNG)

## 使用技術

| 技術 | 用途 |
|------|------|
| HTML | ページ構造の作成 |
| CSS | スタイリング・アニメーション |
| Google Fonts (Noto Sans JP) | フォント |

## 主な機能

- フェードインアニメーション（ページ表示時）
- スキルプログレスバー（アニメーション付き）
- 趣味リスト（ホバーエフェクト付き）
- グラデーション背景
- レスポンシブ対応（スマートフォンでも見やすいレイアウト）
